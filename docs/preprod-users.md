## 🔍 Verification Methodology

1. **Bech32m Address Validation:** Every wallet address is verified as a valid Midnight Preprod address format (`addr_test1...`).
2. **On-Chain Commitment Logs:** Vault commitments generate SHA-256 hashes bound to the connected wallet address.
3. **Continuous Onboarding Mechanism:** New users can connect via the live DApp, test vault encryption/recovery, and submit their wallet address directly into the feedback and onboarding stream.
