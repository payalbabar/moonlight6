# StegoVault User Guide & Troubleshooting

> Note: Detailed usage documentation is available in [`docs/USAGE.md`](docs/USAGE.md).

StegoVault provides client-side steganographic cold storage powered by Midnight Network and 1AM Wallet.

## Key Usage Highlights

- **Connect 1AM Wallet:** Native connection via `window.midnight["1am"]`.
- **Seal Vault:** Drag and drop cover PNG, enter secret + password, authorize on Midnight Preprod, and download `stegovault_secure.zip`.
- **Unlock Vault:** Upload `vault.png`, enter password, verify 1AM Wallet identity, and decrypt secret locally.

For complete troubleshooting and user instructions, see [`docs/USAGE.md`](docs/USAGE.md).
